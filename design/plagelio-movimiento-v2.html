NuevoAnatomía de animejs.com Réplica en Canvas 2D + anime.js

Así está hecha la web que te gustó.

Revisé su código publicado. No hay magia: anime.js mueve números y otra pieza los dibuja. Al lado, una réplica funcional de su sección de stagger con 169 círculos.

  • Escenas por capítulos

    La página se divide en capítulos (intro, toolbox, staggering, clockwork, svgUtils, draggable, scroll…). Cada uno tiene su timeline, que arranca al entrar en pantalla y se pausa al salir.

  • El 3D es three.js

    Cámara ortográfica, InstancedMesh y shaders propios. anime.js no dibuja nada: anima las propiedades x, y, z, rotateZ y escala de objetos JS normales, y en cada onUpdate la escena se vuelve a renderizar.

  • Los demos 2D son canvas

    Una clase pinta círculos y líneas a doble densidad. anime.js reparte los retardos con stagger(…, { grid: [13, 13], from: 'center' }): de ahí la onda que sale del centro.

  • El texto, letra a letra

    splitText separa palabras y letras. La palabra que rota («HTML, WebGL, CSS, Canvas 2D, SVG, anything») sale y entra con un timeline y el punto rojo se desliza. Arriba, en el héroe 3D, está la misma técnica con las palabras de Plagelio.

  • ¿anime.js permite hacerlo?

    Sí. anime.js 4 trae todo lo anterior. Lo único que no incluye es el motor 3D: para eso se suma three.js, como hacen ellos.

// anime.js anima objetos normales; el canvas los pinta
const puntos = cuadricula(13, 13);      // [{ x, y, scale }]
anime.animate(puntos, {
  scale: [{ to: anime.stagger([2.6, .4], { grid: [13, 13], from: 'center' }) },
          { to: 1 }],
  delay: anime.stagger(60, { grid: [13, 13], from: 'center' }),
  loop: true,
  onUpdate: () => dibujar(puntos),   // redibujar en cada frame
});
